# Photon Snapshot 1.0.0

- GIF/WebP animation documents with frame selection, scoped editing, independent duplication, timing, loops, reorder, playback and onion skin.
- New/imported animations, drawing, and document-owned text/shapes with native-resolution rendering.
- Editable `.photonanim` projects, explicit animation/frame exports and encoded-output preview.
- Shared codec-aware format registry, transparency/metadata controls and atomic verified image exports.
- Four-tab image batch conversion with ordered effects, protected destinations, database presets, pause/cancel, progress and summaries.
- Frame shortcuts, pane navigation and complete French/Spanish/Arabic interface catalogs.
- Fixed accordion header minimum-size growth that could hide editing controls.
- File → New groups image and animation creation; Tools precedes Options. Frame and batch lists expose selection-aware context actions.
- Corrected animation colour-profile normalization and cancellation between export preparations.
- Kept long translated adjustment labels visible in narrow panes.
- Fixed the x64 per-user MSI, supported-format registrations, and custom-folder maintenance/removal.

See [animation guide](animation-guide.md), [batch guide](batch-conversion-guide.md), and [format reference](image-format-reference.md).

The new converter was implemented in Photon from the documented interface reference. No Playform source was transplanted for these features. Photon remains MIT licensed.
